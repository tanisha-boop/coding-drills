# Express JSON Database

A simple full-stack web application using Express.js and a JSON file as a mini database.

## Tech Stack

- Node.js
- Express.js
- JSON
- HTML
- CSS
- JavaScript
- Docker

## Features

- Express backend
- JSON-based mini database
- REST API
- Frontend rendering
- Employee directory
- Individual employee API endpoint
- Docker support
